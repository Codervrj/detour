# Detour

Music discovery that balances familiarity with exploration. Detour learns taste from listening
history, scores how adventurous each listener is, and re-ranks recommendations so explorers get
pushed further out while loyalists take gentler steps.

## Run it

```bash
uv run python scripts/create_project.py --with-web   # scaffold (idempotent)
uv run python run.py setup                           # install Python and web deps
uv run python run.py demo                            # pipeline, then API + web together
```

Then open http://127.0.0.1:5173.

**The data is synthetic.** Nothing is downloaded and no credentials are needed. Fifty invented
listeners are generated by `tests/fixtures/make_fixtures.py`. The ListenBrainz ingest in
`detour/ingest/` is not implemented, so every number in the app describes invented listeners.

## Commands

| Command | What it does |
|---|---|
| `run.py setup` | `uv sync`, enable pnpm, install web deps |
| `run.py pipeline` | fixtures to clean to split to train to artifacts |
| `run.py eval` | run the eval harness, write a report |
| `run.py api` | serve the FastAPI app on :8000 |
| `run.py web` | serve the Vite dev server on :5173 |
| `run.py demo` | pipeline, then API and web together |
| `run.py test` / `run.py lint` | pytest, and ruff plus mypy |

`make` is not required and is not installed everywhere; `run.py` is the real entry point and the
`Makefile` simply forwards to it.

## Layout

- `detour/` — pipeline, features, models, re-ranking, eval. All logic lives here.
- `api/` — FastAPI app reading pre-computed artefacts from `artifacts/`.
- `web/` — React + Vite frontend. Design decisions are recorded in `web/DESIGN.md`.
- `evals/` — configs, regression thresholds, generated reports.
- `tests/` — unit, integration and API tests, run on fixtures only.

See `plan.md` for the build order and `CLAUDE.md` for the full specification.
